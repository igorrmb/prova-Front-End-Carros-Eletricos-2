# Projeto Escolar: Portal Carros Elétricos 🚗⚡

Este é um projeto prático desenvolvido puramente em **HTML5**, sem a aplicação de folhas de estilo (CSS). O objetivo principal é demonstrar o aprendizado sobre a estrutura semântica correta, navegação interna, tabelas organizadas, formulários nativos avançados e inclusão de mídias locais.

## 📁 Estrutura de Pastas do Projeto
- `index.html`: Página principal contendo introdução, conceitos, citações e elementos de marcação avançados.
- `pagina2.html`: Apresentação de dados técnicos com tabela real de modelos (BYD, GWM, Tesla) e exibição de vídeo local.
- `pagina3.html`: Formulário completo de cadastro e pesquisa com inputs modernos.
- `img/`: Destinada às imagens usadas nas tags `<figure>`.
- `video/`: Armazena o clipe no formato `.mp4` carregado na segunda página.

## 🛠️ Recursos do HTML5 Aplicados
- **Semântica Completa:** Uso correto de `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>` e `<footer>`.
- **Navegação Fluida:** Menu em lista presente nas 3 páginas permitindo ir e voltar com facilidade.
- **Tabela Complexa:** Matriz de dados com mesclagem de linhas (`rowspan`) para agrupar capacidades de baterias semelhantes.
- **Formulário Avançado:** Inclusão de `type="date"`, `type="range"`, `type="file"`, vinculação de `datalist` para sugestão de marcas, além de atributos como `placeholder` e `required`.
- **Elementos Interativos:** Tags `<details>` e `<summary>` criadas para seções de perguntas comuns.
- **Marcação de Texto Rica:** Aplicação de `<abbr>`, `<mark>`, `<del>`, `<ins>`, `<progress>`, `<meter>`, `<blockquote\>` e `<cite>`.
